# Roomies

Roomies is a web application project developed for the Web Technologies course at Universidad de los Andes.

The platform connects people who have an available room in a shared home with people looking for a place to live.

## Assignment 1

This repository contains the deliverables for Assignment 1:

- Responsive landing page built with HTML, CSS, and Bootstrap
- User stories
- Domain model
- Design decisions document
