# Roomies — User Stories

## Visitor

### US1 — Browse listings

As a visitor, I want to browse published room listings, so that I can see available rooms without creating an account.

### US2 — Search listings

As a visitor, I want to search listings by neighborhood, maximum rent, availability date, and amenities, so that I can find rooms that match my needs.

### US3 — View listing details

As a visitor, I want to view the details of a listing, including photos, rent, availability, description, and property amenities, so that I can decide whether the room interests me.

### US4 — Read property reviews

As a visitor, I want to read reviews from people who visited a property, so that I can better judge whether the property matches what is advertised.


## Member — Seeker

### US5 — Apply to a listing

As a member acting as a seeker, I want to apply to a published listing, so that I can express my interest in renting the room.

### US6 — Withdraw an application

As a member acting as a seeker, I want to withdraw one of my applications, so that I can stop being considered for a room I no longer want.

### US7 — View my applications

As a member acting as a seeker, I want to see the applications I have sent and their current states, so that I can track my progress with each room.

### US8 — Save a listing

As a member acting as a seeker, I want to save a listing, so that I can easily return to it later.

### US9 — Confirm a visit

As a member acting as a seeker, I want to confirm a proposed visit to a property, so that I can arrange a time to see the room in person.

### US10 — Review a property

As a member acting as a seeker, I want to review a property after a completed visit, so that I can share whether the property matched what was advertised.

### US11 — Report a listing

As a member acting as a seeker, I want to report a listing that seems fraudulent, misleading, or offensive, so that moderators can review it.

## Member — Host

### US12 — Register a property

As a member acting as a host, I want to register a property, so that I can publish rooms available in that home.

### US13 — Publish a room listing

As a member acting as a host, I want to publish a listing for an available room in my property, so that seekers can find it and apply.

### US14 — View received applications

As a member acting as a host, I want to see the applications received for my listings, so that I can evaluate people interested in the room.

### US15 — Shortlist an application

As a member acting as a host, I want to shortlist an application, so that I can indicate that I am interested in meeting that applicant.

### US16 — Arrange a visit

As a member acting as a host, I want to propose a date and time for a visit to a shortlisted applicant, so that they can see the property before a decision is made.

### US17 — Accept an applicant

As a member acting as a host, I want to accept one applicant for a listing, so that I can choose who will move into the room.

### US18 — Withdraw a listing

As a member acting as a host, I want to withdraw one of my listings, so that it is no longer visible or open to applications.

### US19 — Mark a listing as rented

As a member acting as a host, I want to mark a reserved listing as rented once the new housemate moves in, so that the listing reflects its current state.

## Moderator

### US20 — Review reported listings

As a moderator, I want to review reports submitted about listings, so that I can determine whether a listing violates the platform rules.

### US21 — Take down a listing

As a moderator, I want to take down a listing that is fraudulent, misleading, or offensive, so that users are protected from inappropriate content.

### US22 — Remove a review

As a moderator, I want to remove an inappropriate review, so that public property reviews remain useful and respectful.

### US23 — Manage neighborhoods

As a moderator, I want to manage the neighborhood catalog, so that listings use consistent and valid neighborhood information.

### US24 — Manage amenities

As a moderator, I want to manage the amenities catalog, so that properties use a consistent set of available amenities.
